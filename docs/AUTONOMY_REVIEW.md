# Разбор: автономный режим пайплайна

Дата: 2026-09-24. Продолжение `ANALYSIS_REPORT.md` (там — отбор моментов).
Здесь — всё остальное: оркестратор, загрузка, транскрибация, вычитка, нарезка,
управление llama-server и конфиг, с прицелом на работу без присмотра (ночной
прогон канала по таймеру).

Скорость не замерялась: выводы сделаны по коду, спорные места проверены
фактически (например, ленивое декодирование faster-whisper 1.2.1).

## Итог

Ядро отбора после рефакторинга в порядке. Слабое место автономного режима —
оркестратор `pipeline.py`:

- ошибка в любом эпизоде останавливает всю очередь;
- Whisper и llama-server (~14 ГБ весов) загружаются заново на каждый эпизод;
- самая дорогая LLM-стадия — вычитка: модель генерирует весь транскрипт заново.

## 2. Эффективность

- **Модели на каждый эпизод.** Цикл «эпизод за эпизодом» убивает и поднимает
  llama-server и загружает Whisper для каждого эпизода. Решение — выполнение по
  стадиям: все транскрипции (одна загрузка Whisper), одна сессия llama-server
  на все LLM-стадии, затем вся нарезка.
- **Вычитка переписывает весь транскрипт.** Промпт требует вернуть каждый
  сегмент. При `parallel: 1` ускоряет только сокращение токенов: возвращать
  только исправленные сегменты; без статьи — вычитывать только отрезки клипов.
- **Вычитка рассинхронизирует слова.** Меняется `segments[].text`, `words`
  остаются сырыми: караоке-субтитры исправленных фраз переходят на
  интерполяцию, а цитаты сверяются не с тем текстом, который видел scout.
  Решение — выравнивать слова по токенам после вычитки.
- **Кэш по наличию файлов.** Смена промптов/квот/модели не перезапускает
  анализ; нарезка пропускается при любом существующем `reel_*.mp4`, а подписи
  пересобираются от новых моментов. Нужны отпечатки входов стадий.
- **Анализ не возобновляется.** Нужен дисковый кэш LLM-ответов.
- **Лишняя работа с медиа:** MP3 320k для каждого эпизода, кодирование
  отбракованных клипов, libx264 вместо NVENC при вшивании субтитров, WAV и
  исходники не удаляются.
- `n_predict: 4096` на все роли — после облегчения scout можно меньше.

## 3. Качество без человека в контуре

- **Фильтры качества после отбора.** `quality_filters.min_duration: 15`
  против stories ≤15 с и highlights 10–30 с: для 90-минутного эпизода под
  отсевом 3 stories и часть из 7 highlights (из 15 клипов). Фильтры — в
  селектор.
- **Умный кроп выключен на свежей установке:** модель MediaPipe не
  скачивается, предупреждение вводит в заблуждение; мелкие лица на общих планах
  не находятся; `face_min_size` не используется; кроп один на клип — при двух
  спикерах кадр посередине.
- **Метаданные YouTube** (`.info.json`: описание, главы, имена) не
  используются.
- **Готовый ролик не проверяется** (длительность, звук, чёрный кадр).
- **Нет регрессионной оценки** на эталонном наборе.

## 4. Чистка

- Мёртвый код: `burn_drawtext_subs.py`, `burn_subs_pillow.py`,
  `render_viral_subs.py`, `scripts/test_models*.py`, промпты
  `refine`/`metadata`/`select_*`.
- `run_pipeline` — около 600 строк в одной функции.
- Транскрипт пишется неатомарно.
- Версии зависимостей не ограничены сверху; yt-dlp, наоборот, надо обновлять.
- Не описан запуск по расписанию.
